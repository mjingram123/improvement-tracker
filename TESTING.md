# QA scenario pass

Run at 375x812 in the in-app browser against http://localhost:8765/ (main branch, `python3 -m http.server 8765 --directory improvement-tracker` from the sandbox root, or the "improve" preview).
Before each pass: clear site data (localStorage, IndexedDB) unless the scenario says otherwise. Report each as PASS or FAIL with steps and a screenshot on FAIL.

1. Fresh load: no console errors. Tab bar shows four tabs, in order, Day / Week / Night / More, each with an outline icon above its label; the current tab is in accent color with `aria-current="page"`. The floating "I feel an urge" button is visible above the tab bar.
2. Default tab: reload the app (or change the device clock) at a few points in the day. Between the rollover hour (More > Schedule > Day ends at, default 4am) and 15:00, it opens on Day. At 15:00 or later, or before the rollover hour, it opens on Night.
3. Day tab: header shows the weekday and date with "morning" underneath. Stretched toggle persists across reload. Morning card shows a "done" badge once Stretched is on and, on hangover-kit days, all four kit items are checked.
4. Hangover kit appears only on the configured days (fake via `settings.hangoverDays` in localStorage if today is not one of them). Turning it on reveals four checks (LMNT, Food, Ibuprofen, Walk); turning it off clears them.
5. Commitments card: Water polo and Dinner out rows appear only on their configured days; Gym always shows. All three persist across reload.
6. Setup checklist: on a fresh install it is the top card on Day with three items (Add to Home Screen, Two reminders, First backup) and a "Done, hide this" button; items are tappable and persist. Tapping "Done, hide this" removes the card from Day and the same three items (still tappable, no "Done" button) appear instead in More under "Getting set up".
7. Floating urge button on every tab: switch through Day, Week, Night, More and confirm the button is visible and tappable on all four, not just one.
8. Night, first visit of the day: opens directly into the 4-step flow at step 1 (Wind-down), with a dot indicator (4 dots, current step highlighted), a disabled/absent Back, a Next button, and a Skip text button.
9. Night flow navigation: Next and Skip both advance to the next dot and mark the step visited; Back returns to the previous step without losing data; tapping a dot jumps straight to that step. Wind-down's Start 15:00 / countdown / Cancel / done-and-reset behave exactly as before.
10. Wind-down keeps ticking correctly off-step and off-tab: start the wind-down timer, then move to another Night step or switch to Day/Week/More; forcing `windDown.endsAt` into the past (via localStorage) still flips it to done with a toast on the next tick, wherever you are.
11. Night summary: after Next/Skip through all four steps (or as soon as the existing partial-done rule is met: wind-down done, or any rating, or a non-blank sentence), Night switches to a summary card listing each section's value with an Edit button. Reloading the tab mid-evening keeps the same visited/step progress (sessionStorage), but a fresh day resets it.
12. Night summary Edit: tapping Edit on any section jumps back into that step, shows a "Back to summary" link, and lets you change the value; using it returns to the summary with the updated value shown.
13. Urge overlay, idle state: tap "I feel an urge" from any tab. A full-screen overlay opens with a close button top right; Escape also closes it. Idle state shows the Scrolling/Porn segmented control, a trigger field (placeholder "Trigger, two words (bored, tired, alone)"), Start 10 minutes, the Shortcuts timer link when `useShortcutTimers` is on, and below it this week's tally ("N rode · M gave in") and the last five urges (time, kind, trigger, outcome).
14. Urge overlay, running state: Start 10 minutes switches to a big countdown, the trigger text, a disabled "Rode it out" and an always-enabled "Gave in", and the line "Wait it out. Rode it out unlocks when the timer ends." Closing and reopening the overlay while a timer runs returns straight to this running state.
15. Floating button while an urge runs: label reads "Riding it out · mm:ss" and updates every second on whichever tab is showing; tapping it reopens the overlay in the running state. Forcing the urge's `endsAt` into the past (via localStorage) enables "Rode it out" in the overlay and changes the floating button text within a second, without a manual refresh.
16. Urge outcome: tapping "Rode it out" (once unlocked) or "Gave in" (any time) logs the outcome, closes the overlay, and updates the week tally and last-five list the next time the overlay is opened. Neither the app nor its manifest/onboarding copy ever mentions scrolling or porn outside the overlay/Night flow, and no slip is ever shown in red.
17. Week: unchanged. Rates show "n of m" with m = days elapsed this week; last week comparison appears when last week has data; sparkline renders with gaps for missing days; Journal lists sentences and slip notes; prev/next week nav works and next is disabled on the current week.
18. More: unchanged. Copy puts JSON on the clipboard and updates "Last backup"; Download triggers a file; Share falls back to Download when unsupported; Restore merges pasted or chosen backups (counts match, existing newer days are not overwritten, junk text shows the error toast); Storage health rows reflect the primary store, mirror, and snapshot count; Schedule day chips and the rollover selector persist; the Shortcuts-timers toggle persists.
19. Failsafe: delete only the localStorage keys, reload: data comes back from the IndexedDB mirror and the green banner on Day says so.
20. Day rollover: with the clock between midnight and the rollover hour, todayKey is yesterday (verify via the logic unit tests with a fixed date) and the app's default tab is Night.
21. Layout: no horizontal scroll on any tab or in the urge overlay. The floating button and tab bar never cover the last input when the keyboard is closed. Dark mode is readable, including the tab icons (stroke follows the accent color on the active tab) and the Night step-dot indicator.
